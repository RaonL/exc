# Class 9 — community reference lab

Source: https://github.com/Mettichi1/WAAP-Bot-Detection-with-F5-XC
Official cross-check: https://clouddocs.f5.com/training/community/f5xc/html/class2/lab2.html

Class 9 contains five independent local exercises: WAF, API endpoint protection, service policy/rate limiting, signature-based bot protection, and endpoint Bot Defense. These adapt existing verified simulation engines. The guide gives manual configuration steps, before/after requests, and logs. Signature catalog tests run in the console and are distinct from the training WAF verifier.

The repository screenshot files 37.png and 57.png are displayed as attributed static references, not current dashboard evidence. Other original screenshots have not all been reproduced. Live dashboards remain local simulated aggregates. Bot endpoint paths use the simulator's dummy app rather than the original hosted lab. No real F5 classification, telemetry collection or network requests are performed by tests.

The F5 icon is the original https://www.f5.com/favicon.ico asset, stored locally at public/brand/f5.ico. The unofficial simulator notice remains visible. This does not imply F5 affiliation.
